# Archive and history

Archive material is evidence about how the project arrived here. It is not
authority for what to build now. Current truth lives in the documents mapped by
[`../README.md`](../README.md).

Three historical files remain at stable paths because code comments, documents
and tools already cite them:

- [`../../DESIGN.md`](../../DESIGN.md) — superseded HUD design. Use
  `docs/STYLEGUIDE.md`, the as-built code and `docs/CONTRACT.md` now.
- [`../HUD_PLAN.md`](../HUD_PLAN.md) — historical HUD plan and rationale. Use
  `docs/STYLEGUIDE.md` for current visual and HUD rules.
- [`../CONTRACT.topdown.old.md`](../CONTRACT.topdown.old.md) — superseded
  top-down contract. Use `docs/CONTRACT.md` for the current build contract.

Do not bulk-move these files into this directory. Their paths are part of the
project's reference history.
