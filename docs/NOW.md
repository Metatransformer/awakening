# Now

**Stage: Pre-production — Core Loop Proof**

## Active question

Does finishing one descent create a specific, voluntary desire for another?

M4's one-floor core-loop prototype is built, but its human fun gate has not
passed. M5 exists as accepted sequencing debt. It does not prove the loop and
does not authorise the next milestone.

**M6 and production content are not authorised.**

## Authorised now

- Changes required to test or sharpen the first-floor loop.
- Combat readability and feel.
- Onboarding needed to let a cold player reach and understand the loop.
- Evidence capture for the active test.
- **Owner amendment 2026-08-12, issue #114:** the low-fidelity generated
  garrison compound, bounded gate-to-Cut approach, one shared civil
  day/night/weather loop, NPC curfew and the Elder's three fixed QoL tracks are
  authorised as a homecoming/return-walk test. This does not authorise M6,
  production environment art or additional overworld content.

## Not authorised

- Broad lore expansion.
- More content volume.
- Polish unrelated to the active proof question.

The active design test is
[`design-tests/CORE_LOOP_PROOF.md`](design-tests/CORE_LOOP_PROOF.md). Its MDA
hypothesis is mapped in [`MDA.md`](MDA.md).

## Possible result

- **Proven:** the precommitted criteria pass. This authorises production
  planning, not automatic production.
- **Promising:** the desired behavior appears, but a criterion misses or the
  reason is unclear. The reward is another small test, not production content.
- **Disproven:** the loop is understood and completed, but does not create the
  intended desire. Reconsider the loop before expanding it.
- **Unknown:** the evidence is invalid or insufficient. Fix the test and run it
  again.
